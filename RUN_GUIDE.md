# 🚀 How to Run Chopra Footwear Industries Website

Follow these simple steps to open and use your website:

### Step 1: Open the Backend Server
1. Open a **new terminal** (Command Prompt or PowerShell).
2. Go to the `server` folder:
   ```bash
   cd server
   ```
3. Start the server:
   ```bash
   node index.js
   ```
   *You should see: "🚀 Chopra Footwear Industries API running on port 5000"*

### Step 2: Open the Frontend Website
1. Open a **second terminal** (do not close the first one).
2. Go to the `client` folder:
   ```bash
   cd client
   ```
3. Start the website:
   ```bash
   npm run dev
   ```
   *You should see: "Local: http://localhost:5173/"*

### Step 3: View the Website
1. Open your web browser (Chrome, Edge, etc.).
2. Type **`http://localhost:5173`** in the address bar and press Enter.
